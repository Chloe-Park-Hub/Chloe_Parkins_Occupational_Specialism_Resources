# Chloe_Parkins_Occupational_Specialism_Resources
This repository stores useful materials that can be used during the Occupational Specialism Examinations. 

### This repository will contain multiple branches with useful information, resources and materials that can be used during the Occupational Specialism examinations.  ###
The branch names will indicate what materials you will be able to find during the exam for easy location. 

Only crucial documents will be moved onto the main branch for easy access. 
Any images uploaded onto branches will be free access unless the image is saved with the initials 'NL' which stands for 'No Licenses'. If you use an image like this, you will need to explain the legal issues and copywrite laws in the exam.
